Commands for managing source repositories.

A source repository is a self-contained collection of source crates (one sources/<lang>.<name>/ directory per source, optionally alongside shared templates/) that gets published as a single source list — the Aidoku Aidoku-Community/sources model. repo build packages every source and assembles the public/ source list (packages + icons + index.min.json); the result can be served locally with repo serve or deployed to GitHub Pages and added to the app as a repo URL.
